# FixDoomfist
The purpose of this website is to spread awareness of gameplay issues that affect the Overwatch character called Doomfist.

# AI disclosure
AI was and is used to help with website styling and some components of Jekyll, as I don't have enough experience to do it in reasonable time without it. AI is **NOT** used in any aspects of bug research, writeup etc. English is not my first language, any help with grammar is appreciated.

# Structure
The .md files in both _bugs and _heroes are generated automatically by my script and are not meant to be interacted with. I will change this and make the script public in the future.
