Doomfist cannot die while in Meteor Strike. This is, thankfully, not bugged. However, if Doomfist is already dead, there is a short window where, if the player presses the ultimate key, the visuals and audio start as if the player has used their ult.

This is purely a visual issue, but some players consider this bug to be incredibly annoying and send a lot of clips of it occurring. Yes, I'm talking about you, 307.
